# 🐍 Snake Game

클래식 스네이크 게임을 HTML5 Canvas로 구현한 프로젝트입니다.

## 기능

- ✅ 방향키로 뱀 조종
- ✅ 먹이 먹고 성장
- ✅ 충돌 감지 (벽, 자기 몸)
- ✅ 점수 시스템
- ✅ 최고점 저장
- ✅ 일시정지/재시작

## 실행 방법

1. 프로젝트 클론 또는 다운로드
2. `index.html` 파일을 브라우저에서 열기
3. "시작" 버튼 클릭
4. 방향키로 플레이!

## 파일 구조

```
snake-game/
├── index.html          # 메인 HTML
├── css/
│   └── style.css      # 스타일시트
├── js/
│   ├── game.js        # 게임 로직
│   ├── renderer.js    # 렌더링
│   └── main.js        # 메인 컨트롤러
└── README.md          # 이 파일
```

## 기술 스택

- HTML5 Canvas
- Vanilla JavaScript (ES6+)
- CSS3
